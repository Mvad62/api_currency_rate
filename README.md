# Конвертер валют

Консольное приложение получает актуальные курсы валют через [ExchangeRate-API](https://www.exchangerate-api.com/) и позволяет конвертировать сумму между валютами.

## Возможности

- Получение курсов для выбранной базовой валюты.
- Вывод курсов RUB, EUR и GBP, если сервис их предоставляет.
- Конвертация между любыми валютами, доступными в ответе API.
- Локальный кэш в `currency_rate.json`, действующий 24 часа.
- Повторное использование актуального кэша для той же базовой валюты.

## Требования

- Python 3.9 или новее.
- Доступ к интернету для получения свежих курсов.

## Установка и запуск

Откройте терминал в папке проекта и выполните:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python currency.py
```

При необходимости вместо `python` используйте команду `py`.

Приложение запросит код базовой валюты, например `USD`. Затем оно покажет выбранные курсы и предложит выполнить конвертацию.

## Структура проекта

- `currency.py` — точка входа и совместимый интерфейс для запуска приложения.
- `cli.py` — интерактивная командная строка и логика конвертации.
- `api_client.py` — запросы к API и обработка ошибок ответа.
- `storage.py` — чтение, запись и проверка срока действия кэша.
- `requirements.txt` — список зависимостей.
- `currency_rate.json` — локальный кэш курсов; файл обновляется приложением.
